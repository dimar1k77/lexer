# Лексический и синтаксический анализатор C++

Программа читает исходный код на C++ (упрощённое подмножество языка), посимвольно разбивает его на токены и проверяет правила написания.

## Что делает

**1. Лексический анализ (лексер)** — проходит текст посимвольно и возвращает массив токенов:

| Тип токена | Примеры |
|---|---|
| Ключевое слово | `if`, `for`, `while`, `return` |
| Тип данных | `int`, `double`, `char`, `string` |
| Идентификатор | `a`, `sum`, `total` |
| Число | `10`, `3.14`, `2.5f` |
| Строка / символ | `"Hello"`, `'a'` |
| Оператор | `+`, `==`, `<<`, `++`, `&&` |
| Разделитель | `( ) { } [ ] ; ,` |
| Директива | `#include <iostream>` |

Комментарии `//` и `/* */` пропускаются.

Лексические ошибки: недопустимый символ (`@`, `$`, русские буквы вне строк), неверное число (`3.14.15`, `12abc`), незакрытая строка, незакрытый комментарий.

**2. Синтаксический анализ** — обходит список токенов и проверяет:

- все скобки `()`, `[]`, `{}` закрываются и закрываются правильной скобкой;
- переменная объявлена перед использованием;
- переменная инициализирована перед использованием (`int a; b = a;` — ошибка);
- нет повторного объявления переменной в одной области видимости;
- вызываемая функция объявлена;
- в конце операторов нет пропущенной `;`.

Учитываются области видимости `{ }`, параметры функций, переменные цикла `for`, ввод через `cin >> a`.

## Сборка и запуск

```bash
g++ -std=c++17 -o analyzer main.cpp
./analyzer test_ok.cpp       # корректная программа
./analyzer test_errors.cpp   # программа с ошибками
```

На Windows: `g++ -std=c++17 -o analyzer.exe main.cpp`, затем `analyzer.exe test_errors.cpp`.

## Пример вывода

```
========== РЕЗУЛЬТАТ ==========
Найдено ошибок: 3
[Семантическая] строка 7, позиция 13: переменная 'a' используется без инициализации
[Лексическая] строка 12, позиция 16: неверная запись числа '3.14.15'
[Синтаксическая] строка 19, позиция 14: пропущена ';' после '7'
```

## Файлы

- `main.cpp` — анализатор
- `test_ok.cpp` — пример корректного кода
- `test_errors.cpp` — пример кода с ошибками
